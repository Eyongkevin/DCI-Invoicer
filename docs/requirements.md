# Requirements

## Functional Requirements

- Upload spreadsheet containing certain data to generate invoice
- Configure user's profile
- Generate invoice by a click of a button

- Adjust the status of of a generated invoice (Pending, Paid, Unpaid)
- Input tasks into the system
- Auto-generate invoice with a cron job

## Non-Functional Requirements

- Use Design-First approach
- Set CI-CD with github actions
- Use TDD for development, both API and frontend
- Build backend API with Django Rest Framework and frontend with Reactjs
- Build a desktop and mobile app client using Kivy MD (Later)
- Backend and Front end hosted on AWS
- Track progress using todo-app PERN locally.
- Release APIs for the MVP by December ending.
