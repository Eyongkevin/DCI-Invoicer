# Acceptance Test / User Stories

- As a `Freelancer`, I want to `insert tasks` so that an invoice will be generated
- As a `Freelancer`, I want to `Modify Tasks` so that my tasks are correct and true.
- As a `Freelancer`, I want to `Delete Tasks` so that I rid of unwanted tasks
- As a `Freelancer`, I want to `Set a cron job to auto-generate the invoice periodically` so that I can email them to DCI

## MVP - Minimum Viable Product

- As an `Admin`, I want to `Create freelancer's IAM account` so that I can hand over their credentials for further actions like completing their profile, uploading spreadsheets and generating invoices.
- As an `Admin`, I want to be able to `Reset freelancer's password` so that a new password is given to those who have forgotten thiers.
- As an `Admin`, I want to be able to `Deactivate/Activate and Delete` a freelancer so that I can easily control how many freelancers are in the system and their status.
- As an `Admin`, I want to be the only one to `See the list of all registered freelancers` so that I can manage them.

- As a `Freelancer` I want to `Generate invoice in PDF` so that I can email them to DCI
- As a `Freelancer`, I want to `upload a spreadsheet` so that tasks can be extracted from it and an invoice generated.
- As a `Freelancer` I want to `Configure my profile` so that some information can be taken from my profile when invoice is been generated.
- As a `Freelancer`, I want to be able to `update/change my password` so that it's different and unique to me.
